# 계획서 작성 · 갱신

계획서는 `docs/plans/NNNN-kebab-제목.md`에 둔다. 번호는 기존 최대 번호 + 1 (4자리).

## 새 계획

1. `docs/plans/_template.md`를 복사해 채운다. 사용자가 이미 쓴 계획이 있으면 그 문장을 살리고 형식만 맞춘다.
2. "완료 기준"은 사람이 읽고 판단하는 문장이 아니라 **돌려서 확인할 수 있는 것**으로 쓴다:
   `pnpm test -- scene` 통과 / `pnpm snap --only=ar` 결과가 디자인 원본과 일치 / 특정 타입이 존재 등.
3. 모션이 들어가는 작업이면 어떤 `TIMELINE` 키와 어떤 테스트가 명세가 되는지 적는다.
4. `docs/plans/README.md`의 목록 표에 한 줄 추가한다.

## 진행 중 · 완료

- 작업하면서 체크박스를 갱신하고, 상태(`계획`/`진행`/`완료`/`보류`)를 frontmatter와 목록 표 둘 다 바꾼다.
- 계획과 다르게 구현했으면 "변경 기록"에 이유를 한 줄 남긴다.
- 계획을 지우지 않는다. 폐기하면 상태를 `보류`로 두고 이유를 적는다.
