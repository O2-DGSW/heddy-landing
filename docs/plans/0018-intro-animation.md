# 첫 화면 소개 애니메이션 (이슈 #70)

## 왜

첫 화면을 45초 소개 영상으로 바꾸기로 했다. mp4(18.7MB)는 문구 하나도 고칠 수 없고 첫 화면을 느리게 해서, 영상을 만든 After Effects 빌드 스크립트(`Heddy_Intro45_Build.jsx`)를 웹 코드로 옮긴다.

## 결정

- 무대 1920×1080(원본 컴프)을 데스크톱에서는 cover로 채우고 모바일은 contain으로 보존한다.
- #76: 첫 방문은 첫 문구 완성 시각(2.4초)부터 즉시 표시하며 이후 반복은 0초부터 원래 타이핑을 재생한다. 현재·다음 장면만 마운트하고 뒤 장면 코드는 분리한다.
- 엔진(`widgets/intro/model/track.ts`): AE 스크립트의 `seg()`(구간 보간)·`pop()`(outBack 근사)과 HTML 원본 이징(out3·out5·inOut3·inOut5·in3·linear)을 그대로 옮겼다.
- 레이어(`model/layer.ts`): 위치 = 기준점, 크기·회전은 기준점 중심(AE와 같음). 텍스트 기준점은 기준선(글자 상자 위 + 0.95 × 크기, 행간 1.19).
- 장면 S01~S15: 계산은 `model/scenes/*`(시각 → 레이어 상태, 순수 함수), 화면은 `ui/scenes/*`. 장면 구간 밖이면 숨기고 계산하지 않는다.
- 문구는 `INTRO_COPY`(원본 COPY 그대로), 장면 구간·글자 폭은 `INTRO`·`INTRO_LAYOUT`(`shared/config/motion.ts`).
- 원본 익스프레션 대응: S02·S07 슬롯(거리로 불투명도, 속도로 흐림), S09 캐러셀(선택 칸 c), S13 물결선(SVG polyline, 흐르는 사인파), S06·S12 떠다니는 아이콘(sin).
- 자간 애니메이션(S09 · S14) 값은 원본 영상에서 px로 벌어져 px로 더한다.
- 소리: 없음(이슈 #94에서 소리 버튼과 오디오 파일 제거). 소리 없이 자동 재생하고 48.91초마다 반복.
- v16(이슈 #96, 내레이션 기준 48.91초): 장면 안 키프레임은 원래 시각 그대로 두고, `INTRO.warp`([화면 시각, 원래 시각] 기준점, 사이는 직선)로 장면마다 늘이거나 줄인다. `useIntroScene`이 장면 구간(화면 시각) 판정 후 `introSceneTime`으로 바꾼 원래 시각을 장면 계산에 넘긴다. 장면 페이드는 원래 시각으로 바꾸면 v5와 같다.
  - 내레이션에 맞춘 장면 안 시각: S01 타이핑, S02 '하나면 충분' 진한 글자(4.887~5.05초), S04 라벨 강조, S07 마지막 문구(착지 + 1.4초), S12 제목(32.33초), S13 둘째 줄(35.89초), S14 글자(38.05초부터 0.13초 간격).
  - 이미지: 시술기록 카드 12장(얼굴 가운데 크롭), 스타일 추천 화면(Top3 교체). 크기는 같다.
  - 명세: `clock.test.ts`(구간·시간 재배치), `scenes/retiming.test.ts`(장면 안 시각).
- 화면 밖이면 멈추고, 동작 줄이기면 S14("다음 스타일의 기준이 되다")에서 멈춘다. `?intro-t=초`로 시각을 고정할 수 있다(확인용).
- 엔딩 QR은 원본 이미지(`https://heddy.site/download?src=poster`, store 없음 → 소개 페이지)를 그대로 쓴다.
- 모바일: 히어로 자리에 16:9 카드로 넣는다(위젯끼리 가져다 쓰지 않게 페이지가 `MobileLanding`에 넣어 준다). 데스크톱 연결은 한 화면씩 넘기는 구조 전환과 함께 한다(지금 3D 폰 합체가 페이지 스크롤 px 기준이라 앞에 화면을 끼우면 어긋난다).
