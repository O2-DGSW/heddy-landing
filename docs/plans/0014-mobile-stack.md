# 모바일 전용 랜딩: 토스식 쌓기 구성

## 왜

모바일에서 고정 3D 폰이 스크롤에 맞춰 움직이는 방식은 무겁다(사용자 피드백). 이 방식은 0013에서 크기·배치만 다듬었다. toss.im 모바일처럼 섹션을 쌓고 가벼운 등장 효과만 쓰는 모바일 전용 랜딩으로 바꾼다. 이슈 #52.

참고: [toss.im](https://toss.im/) 모바일(iPhone 13 크기로 직접 스크롤해 확인)

- 고정 요소는 헤더 하나다. 섹션이 위에서 아래로 쌓인다.
- 기능 하나 = 회색 둥근 카드 안 앱 화면 + 굵은 제목 + 회색 설명.
- 스크롤마다 움직이는 3D·폰이 없다.

## 결정

- **폭 1024px 미만(`lg` 미만) = 모바일**
  - 데스크톱 섹션·3D 폰 레이어는 CSS로 숨긴다.
  - 3D(Spline)·폰 화면 이미지는 `useMediaQuery`로 데스크톱일 때만 시작한다.
  - 모바일에서 캔버스 0개, Spline 요청 0건을 확인했다.
- **`MobileLanding`**(widgets/mobile-landing)
  - 섹션 순서·문구는 데스크톱과 같다(`SECTION_KEYS`·`COPY.sections`, 명세 테스트).
  - 섹션마다 회색 카드 안 평면 폰 목업 하나. 공유는 목업 두 대, AR은 어두운 톤.
  - 히어로는 평면 목업 두 대(홈 · AR)를 V자로 기울인다(Spline 이미지 아님, 사용자 요청).
- **평면 폰 목업**(`public/screens/mobile/phone-frame.svg`)
  - 직접 그린 SVG: 금속 테두리 · 베젤 · 다이내믹 아일랜드 · 측면 버튼, 상표 요소 없음.
  - 화면 이미지(402×874)를 뚫린 자리에 끼우고 목업을 위에 겹친다.
  - Apple 공식 목업은 쓰지 않는다. 내려받으려면 라이선스에 동의해야 하고, 그 약관이 기기 이미지 수정을 금지한다. 요청대로 상표를 지우면 약관 위반이 될 수 있다.
- **데스크톱 히어로 포스터**: 미리 받기를 데스크톱 미디어 조건으로만 걸고 이미지는 lazy. 모바일에서는 받지 않는다.
  - 리포트는 지표 4개를 정지 막대로, 마지막 섹션은 스토어 버튼을 넣는다.
- **화면 이미지**(`public/screens/mobile/`)
  - 피그마 landing 프레임을 2배로 내보내 webp로 만들었다. 긴 화면은 한 화면 비율로 위쪽만 쓴다.
    - 리포트 964:1921, 추천 964:2081, AR 964:2610, 공유 QR 964:2416, 공유된 기록 980:2940
  - 기록 화면은 데스크톱 기록 화면과 같은 배치로 합성했다(`computeSettledRecordCards`).
- **움직임**: `Reveal`(shared/ui)
  - 화면에 들어오면 한 번, 아래에서 살짝 떠오르며 나타난다(IntersectionObserver + CSS transition, 스크롤 프레임 계산 없음).
  - 첫 화면(히어로)은 처음부터 보인다(LCP).
  - 동작 줄이기면 효과 없음.

## 변경 기록

- 2026-10-14: 조사·작성·구현·측정.
- 2026-10-14: 사용자 요청으로 CSS 베젤·Spline 이미지 대신 평면 폰 목업(직접 그린 SVG)으로 바꿨다.
- 2026-10-14: 스크롤하면 카드 안 목업이 위로 올라와 아랫부분(탭바)까지 보이게 했다(사용자 요청). 방식은 다음과 같다.
  - 스크롤 연동 CSS 애니메이션(`animation-timeline: view()`)이라 JS 프레임 계산이 없다.
  - 올라갈 거리는 `phoneRisePercent`(명세 테스트)로 정한다.
  - 함정 1: 단축 `animation`은 재생 시간 0s가 들어가 끝 상태로 굳는다. 그래서 속성을 하나씩 쓴다.
  - 함정 2: 카드 `overflow: hidden`은 스크롤 컨테이너라 기준이 카드로 잡힌다. 그래서 `overflow: clip`을 쓴다.
  - 지원 안 하는 브라우저·동작 줄이기에선 움직이지 않는다.
- 2026-10-14: 추천 섹션 폰 목업을 토스 상품 카드식 캐러셀로 바꿨다(사용자 요청, 토스 "상품 판매와 정산" 참고). 카드는 추천 결과 Top 3(데스크톱 추천 화면과 같은 문구·사진 영역)다. 2.8초마다 다음 카드(마지막 다음엔 처음), 스크롤 스냅으로 손 넘김, 만지면 6초 쉬고, 화면 밖·동작 줄이기면 자동 넘김 없음. 아래 점으로 현재 카드 표시.
