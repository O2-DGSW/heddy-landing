# 카피 가독성과 AR 스크롤 막힘 (이슈 #58)

## 왜

0015에서 폰을 키운 뒤 폰이 카피보다 먼저 눈에 들어와 사용자가 무엇을 하는 화면인지 읽기 어렵고, 폰이 화면 오른쪽(스크롤바 쪽)에 붙어 보였다. 또 트랙패드로 AR 구간을 지나면 스크롤이 3초 넘게 막혔다.

## 범위

- 포함: 데스크톱 폰 크기·위치, 레이아웃 폭(스크롤바), 섹션 글자 크기, 스크롤 멈춤 해제 조건
- 포함(추가): 섹션 기능 이름표 — record의 "01 — 시술기록 저장"처럼 리포트·추천·AR·공유에 02~05 이름표(사용자 확정)
