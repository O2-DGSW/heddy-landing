# 계획서

직접 쓴 계획, 또는 Claude에게 "계획 짜줘"라고 해서 만든 계획을 모아두는 곳입니다.
Claude는 작업을 시작하기 전에 여기서 관련 계획을 찾아 읽고, 끝나면 체크리스트를 갱신합니다.

- 새 계획: `_template.md`를 복사해서 `NNNN-짧은-제목.md`로 저장 (번호는 이어서)
- 상태: `계획` → `진행` → `완료` (접으면 `보류`, 지우지 않기)
- 완료 기준은 가능하면 **돌려서 확인할 수 있는 것**으로 (테스트 이름, `pnpm snap` 결과, 명령어)
