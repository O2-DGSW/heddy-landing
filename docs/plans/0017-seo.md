# 구글 검색 노출 SEO 기본 설정 (이슈 #68)

## 왜

운영 사이트에 `robots.txt`·`sitemap.xml`이 없고 제목 "Heddy", 설명 "헤디 랜딩 페이지"뿐이라 "헤디"·서비스 키워드로 검색해도 사이트가 잘 나오지 않았다.

## 범위

- 포함: robots · sitemap · 메타데이터(제목·설명·canonical·Open Graph·트위터 카드) · JSON-LD · 공유 미리보기 이미지 · 서치 콘솔 확인 메타(환경변수)
- 제외: 서치 콘솔 등록·사이트맵 제출(사용자 계정 작업), 네이버 서치어드바이저

## 결정

- 대표 주소는 실제로 열리는 `https://www.heddy.site`(`SEO.canonicalUrl`). heddy.site는 www로 308 이동한다. QR용 `SITE_URL`(heddy.site)은 바꾸지 않는다.
- 제목 `Heddy(헤디) | {히어로 본문}`, 설명 `{히어로 본문}. {아카이브 본문}` — 기존 카피만 잇는다.
- robots: `/` 허용, `/download`(스토어 이동)·`/mobile`(웹앱) 제외.
- JSON-LD: WebSite(Heddy, 헤디) + Organization(로고 `logo-symbol.png`, 문의 메일, Instagram·GitHub).
- 공유 미리보기 `public/og.png`(1200×630): 1440×756 히어로 화면을 줄인 것.
- 구글 서치 콘솔 HTML 태그 확인 값은 서버 환경변수 `GOOGLE_SITE_VERIFICATION`(없으면 태그 없음). 도메인(DNS TXT) 확인이면 필요 없다.
