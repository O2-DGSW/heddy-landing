# 마지막 섹션: 홈 화면 폰과 스토어 버튼

## 왜

사용자가 준 레퍼런스 이미지대로 마지막 섹션(closing)을 구성한다. 이슈 #40.

- 왼쪽: "다음 시술 전에, / 헤디에 기록부터" 카피, 그 아래 검정 카드형 스토어 버튼 두 개("다운로드" + 스토어명).
- 오른쪽: 정면을 보는 큰 폰이 홈 화면을 보여 준다.
  - 홈 화면 구성: 다음 시술까지 D-12, 지난 컬러 카드, 최근 기록 3건.

## 범위

- 포함
  - 3D 폰 A가 share에서 이어서 움직인다(사용자 선택).
    - share 고정이 끝나는 동안 B가 빠진다.
    - 그 사이 A는 오른쪽으로 가며 커지고, 화면은 홈으로 바뀐다.
  - 홈 화면은 피그마 landing / home(1003:3048)을 쓴다(사용자 요청, 처음엔 이미지대로 HTML을 짰다가 교체).
    - 움직임이 없는 화면이라 3배로 내보낸 이미지(`public/screens/closing/home.webp`)로 쓴다.
    - 피그마 캔버스 배경이 비친 둥근 모서리 바깥은 화면 배경색으로 채웠다.
  - 스토어 버튼은 App Store · 원스토어를 유지한다(사용자 선택).
    - 이미지의 Google Play는 쓰지 않는다. 실제 스토어와 환경변수가 App Store · 원스토어뿐이다.
    - 모양만 이미지대로 바꾼다. `/download` 경유는 그대로다.
  - 스토어 버튼은 작게 줄이고 로고를 붙인다(사용자 요청).
    - App Store: Apple 로고(Simple Icons CC0, 흰색).
    - 원스토어: 공식 사이트(m.onestore.co.kr) 파비콘 192px.
  - 페이지 맨 아래 푸터를 둔다(사용자 요청).
    - 로고 + © 2026 Heddy.
    - 운영 O2, 문의 teamo2.10th@gmail.com (heddy-app 이용약관 "문의처"와 같다).
    - SNS: Instagram(heddy.o2), GitHub(O2-DGSW).
    - 이용약관·개인정보처리방침 링크는 이번엔 넣지 않는다(랜딩에 페이지가 없다, 사용자 선택).
- 제외
  - 3D 폰의 뒤로 눕힘(rotateX 8°)은 그대로 둔다.
    - RecordRig 회전은 기록 스택이 매 프레임 쓴다.
    - closing에서만 바꾸려면 기록 스택 모델과 섞여야 한다.
  - 모바일은 위치·크기를 바꾸지 않는다. 지금처럼 가운데로 돌아온다.

## 결정

- closing 폰 자세(데스크톱)
  - 가로 중심 0.78W, 세로 중심 0.5H.
  - 폰 높이는 화면 높이의 80%다. 단, 오른쪽 여백 안에 들어가게 줄인다.
  - 배율 k = 폰 높이 / (615·S)이고, 1보다 작아지지 않는다.
- 3D 적용
  - RecordRig 배율을 k로 둔다.
  - 화면 오버레이도 같은 k로 키운다(원근 안쪽 `scale3d`).
  - 그림자 바닥(ShadowCatcher)도 k배 아래로 내린다. 폰이 바닥을 뚫지 않게 하려는 것이다.
- 이동 구간
  - share 고정 끝 ~ share.end에 기존 `back` 이징을 그대로 쓴다.
  - 화면 전환은 share 고정 끝 기준 뷰포트 높이 25~65% 구간이다.
  - 이유: 원본의 "share 끝 이후 30~70%"는 페이지 끝을 넘어서 도달하지 못했다(그래서 closing에 QR 화면이 남아 있었다).
- 푸터가 올라오면 폰 A도 그만큼 페이지와 함께 위로 빠진다(closing.top 이후 스크롤 양). 푸터는 폰 레이어(z-40) 위(z-50)라 그림자가 덮지 않는다.
- CSS 폰 화면: 히어로 홈(실제 앱 스크린샷)과 closing 홈(이미지 디자인)은 다른 화면이다. 키를 `home` / `closingHome`으로 나눈다.
