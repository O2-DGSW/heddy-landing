# AR 섹션: 다크 패널과 3D 폰 스타일 전환

## 왜

레퍼런스 영상 두 개를 따라 AR 섹션을 구성한다. 이슈 #34.

- 영상 1(2026-10-12 23:49): 흰 화면에서 "거울 앞에 | 앉기 전에" 사이 pill이 커져 다크 패널이 된다. 이어서 패널 문구가 나오고, 카피와 폰이 나타난다.
- 영상 2(2026-10-13 09:59): 폰 안 AR 화면에서 스타일 캐러셀을 넘기면 캐릭터 머리가 바뀐다.

## 범위

- 포함
  - `docs/design/spec.md` §5 ar 수치로 pill → 다크 패널 → 패널 문구 → 카피를 구현한다.
  - 다크 패널 위에서는 헤더 배경을 투명하게 하고 로고를 숨긴다.
  - 3D 폰(Spline)이 추천 끝에서 페이지와 함께 위로 빠졌다가, AR에서 아래에서 올라오며 다시 나타난다(spec §3).
  - CSS 폰 넘김은 ar 고정 끝으로 옮긴다.
  - AR 화면은 피그마 S5-AR화면1·2·3(964:2610 / 2668 / 2814)을 HTML로 옮긴다.
  - 스타일 3단 전환은 영상 2 방식이다.
    - 다음 썸네일에 터치 표시가 나타난다.
    - 캐러셀이 옆으로 밀려 선택이 가운데로 온다.
    - 캐릭터 이미지와 스타일 이름이 바뀐다.
    - 순서는 일자 풀뱅 → 다운펌 → 가르마 댄디컷이다.
- 제외
  - 영상 2 끝에서 다시 일자 풀뱅으로 돌아가는 부분(3단까지만).
  - share 섹션(지금 CSS 폰 그대로).

## 결정

- 폰 본체는 Spline이고, 화면은 HTML로 투영한다(추천 섹션과 같은 방식, `docs/plans/0007`).
- 캐러셀은 원형이다: [⊘, 일자 풀뱅, 다운펌, 가르마 댄디컷, 추가 스타일].
  - 선택과의 거리에 따라 크기는 80 / 62 / 50 px이고, 간격은 25이다(피그마).
- 스타일 가중치는 spec 식 그대로 쓴다: t2 = R(p, .62~.72), t3 = R(p, .80~.90).
  - 이 안에서 터치 표시 → 캐러셀 밀기 → 캐릭터 크로스페이드 순으로 진행한다.
- 카피는 피그마 S5 문구를 쓴다. `COPY.phoneScreens.ar.styles`를 S5 라벨로 교체한다.
