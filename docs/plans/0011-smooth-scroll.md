# 관성 스크롤과 AR 패널 확대 개선

## 왜

사용자 피드백: "전체적인 흐름이 뚝뚝 끊긴다", "AR 들어가기 전 네모 박스가 스크롤 한 번에 조금 빨리, 자연스럽게 커져야 한다". 이슈 #43.

- 휠 한 번에 페이지가 뚝 점프해서 폰·문구 모션이 계단처럼 보였다(사용자 선택: 스크롤 자체가 끊김).
- AR pill은 3단계(a · b · c)를 따로 이징해서 단계 사이마다 거의 멈췄다 다시 커졌다. 큰 단계에선 반지름이 짧은 변 절반이라 타원처럼 보였다.

## 범위

- 포함
  - 관성 스크롤(마우스 휠·트랙패드)
    - 휠 입력은 목표 위치만 옮긴다.
    - 실제 스크롤은 반감기 100ms로 목표를 따라간다(`SMOOTH_SCROLL`, `shared/lib/scroll/useSmoothWheelScroll`).
    - 프레임은 실제 스크롤 위치에서 그대로 나오므로 모든 모션이 같이 부드러워진다.
  - AR pill 확대
    - 한 곡선(로그 스케일 단조 3차 보간)으로 잇는다.
    - 구간을 ar 진행도 .02~.28에서 .02~.14로 줄인다.
    - 반지름 상한은 40px이다.
    - 패널 문구 in을 .15~.20으로 당긴다.
- 제외
  - 터치: 기본 스크롤을 쓴다.
  - 키보드·스크롤바: 기본 스크롤을 쓴다. 관성 애니메이션 중에 들어오면 애니메이션을 멈춘다.
  - reduced motion: 관성 스크롤을 켜지 않는다.

## 결정

- 헤더가 휠을 먼저 가져간다(아래로 스크롤하면 헤더가 먼저 숨는 동작).
  - 헤더 휠 리스너를 캡처 단계로 옮겼다.
  - 관성 스크롤은 `defaultPrevented`면 건너뛴다.
  - 헤더가 숨은 뒤 남는 양은 `smoothScrollBy`로 넘긴다.
- 안쪽 스크롤 영역(팝오버 등)이 스크롤할 수 있으면 휠을 그쪽에 맡긴다.
- 라이브러리(Lenis 등) 없이 기존 엔진 방식(순수 함수 + rAF, `docs/decisions/0002`)으로 만든다.
