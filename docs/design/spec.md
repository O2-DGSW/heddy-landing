# Heddy Landing v2 — 디자인 명세 (원본에서 추출)

Claude Design `Heddy Landing v2.dc.html`의 마크업과 `update()` 로직에서 옮긴 값이다.
구현할 때는 이 값을 `src/shared/config/*.ts`로 옮기고, 이후로는 코드와 테스트가 단일 출처가 된다.

## 1. 섹션 순서 · 높이

| 코드 키 | 원본 키 | 높이(vh) | 카피 |

| archive | s3 | 220 | 흩어진 기록이, / 한 화면으로 — 갤러리, 메모, 카톡에 흩어져 있던 시술 기록을 / 헤디 하나에 모았어요. |
| record | s4 | 600 | (eyebrow) 01 — 시술기록 저장 · 한 번의 시술이, / 한 장의 기록으로 — 사진 몇 장이면 기록이 끝납니다. / 스크롤을 내릴수록 기록이 시간순으로 쌓여요. |

- 높이 = `100 + (base - 100) × scrollLength` (scrollLength 기본 1). 섹션 진행도 p = (scrollY − top) / (top + height − 뷰포트높이 − top), 0~1로 자름.
- 원본 s2는 삭제됨.
- 헤더: 로고 + "앱 다운로드" 버튼 → QR 팝오버("휴대폰으로 스캔하세요" + 스토어 버튼). 바깥 클릭·ESC로 닫힘.

## 2. 폰 목업 · 레이아웃

- 폰: 300×615, 프레임 `#1C1E20` radius 42, 화면은 inset 6px(288×603) radius 38 — 3D 폰과 같은 얇은 베젤(원본 inset 10, 2026-10-05 조정), 배경 `#FBFBFB`. 그림자 `0 40px 70px -30px rgba(13,13,13,.45)`.
- 폰 두 대(A=메인, B=보조)는 **모든 섹션 위에 떠 있는 fixed 레이어 하나**에 있다.
- 배치: `translate(x−150, y−307.5) rotate(r) scale(S)`, (x,y)=폰 중심.
- 데스크톱(≥1024): S = min(0.8, H×0.5/615, W/1400) (원본 min(1, H×0.78/615, …)에서 줄임, 2026-10-01), 중심 (0.65W, H/2+20) (원본 0.7W). 카피는 좌측 max 40vw, 세로 가운데.
- 모바일(<1024): S = min(0.52, H×0.39/615, W/620) (원본 min(0.62, H×0.46/615, …)에서 줄임), 중심 (0.5W, 0.7H). 카피는 상단 14vh부터.
- 이징은 전부 easeInOutCubic: `t<.5 ? 4t³ : 1−(−2t+2)³/2`.

## 3. 폰 A/B 자세 (R = 구간 진행도, E = 이징)

- **hero → archive 수렴**: c = E(R(p_archive, 0~0.72)). 회전축은 폰 하단 중심(pivot = 307.5×S).
  `V(off, deg) = [cx + off + pivot·sin(deg), cy + pivot − pivot·cos(deg)]`, tilt=12°, dx=(데스크톱 105 / 모바일 80)×S
  A = V(−dx(1−c), −tilt(1−c)), 회전 −tilt(1−c) / B = V(dx(1−c), tilt(1−c)), 회전 +tilt(1−c)
  B 불투명도 = 1 − R(p_archive, 0.72~0.86). archive 끝 이후 B = 0.
- **recommend 끝 ~ ar 시작**: A가 페이지와 함께 위로 빠짐 (yOffset = −(scrollY − recommend 고정 끝)). 3D 폰도 같은 식으로 빠지고, AR 재등장부터 ar 고정 끝까지 다시 3D 폰이다(2026-10-13, `docs/plans/0008`).
- **ar**: A 재등장 yOffset = (1 − E(R(p_ar, 0.46~0.56))) × 90 × S, 불투명도 R(p_ar, 0.46~0.53).
- **share**(ar.end 이후): sh = E(R(p_share, 0.38~0.52)) (원본 0.10~0.32, 2026-10-13 레퍼런스 영상 순서로 미룸, `docs/plans/0009`), back = E(R(scrollY, share 고정 끝~share.end)) (원본 share.end~closing.top은 길이 0)
  A.x = lerp(lerp(cx, cx−0.13W, sh), cx, back) (모바일 0.29W) · B.x = lerp(lerp(W+220S, cx+0.13W, sh), W+220S, back) (모바일 0.73W)
  B 회전 lerp(lerp(10, 0, sh), 10, back), B는 sh>0 && back<1일 때만 보임. QR 비행 = R(p_share, 0.56~0.70). 폰 두 대 모두 Spline 3D(A = RecordRig, B = ShareRigB).

## 4. 폰 화면 전환 (크로스페이드)

- ar 시작 전: 홈 → (archive 끝) 기록 → (record 끝) 리포트 → (report 끝) 추천

- 폰 B: ar 전엔 AR 화면, 이후엔 스캔 → 웹뷰(R(p_share, 0.70~0.80))

## 5. 섹션별 모션

- **record (포커스 밴드)** — 구현은 3D 기록 스택으로 대체됨(`docs/plans/0004`). 레일·큰 날짜 색·캡션은 아래 수치 그대로:
  raw = R(p, 0.06~0.94)×11, k = min(10, ⌊raw⌋), fc = raw≥11 ? 11 : k + lerp(frac, E(frac), 0.5).
  행 j: y = 312 − 21 + (j − fc)×48, 거리 d = |j − fc|, f = clamp(1 − d), appear = clamp(fc − j + 1).
  흐린 행 opacity = f>0 ? 0 : 0.28×appear / 포커스 행 opacity (0.28 + 0.72f)×appear, transform translate(−52f, y) scale(1 + 0.04f), 배경 rgb(245,243,239)→흰색, 그림자 0.10f, 이름색 rgb(92,88,80)→rgb(13,13,13), 날짜색 rgb(163,158,148)→rgb(107,112,117).
  포커스 레이어는 폰 A와 같은 transform. 좌측 레일 scaleY(0.08 + 0.92p), "핀 진행 {8 + 92p}%".
  큰 날짜: 현재 기록 날짜, 색 rgb(214,208,196)→rgb(13,13,13) (fc/11), 캡션 "첫 기록" / "기록 N건 · Y년 M개월".
