# Heddy Landing v2 — 디자인 명세 (원본에서 추출)

Claude Design `Heddy Landing v2.dc.html`의 마크업과 `update()` 로직에서 옮긴 값이다.
구현할 때는 이 값을 `src/shared/config/*.ts`로 옮기고, 이후로는 코드와 테스트가 단일 출처가 된다.

## 1. 섹션 순서 · 높이

| 코드 키 | 원본 키 | 높이(vh) | 카피 |
|---|---|---|---|
| hero | s1 | 100 | 내 머리의 기록이, / 다음 스타일의 기준이 되다 — 펌·컬러·시술 사진을 한 곳에 기록하고, / AI 분석과 AR 프리뷰로 다음 스타일을 미리 확인하세요. |
| archive | s3 | 220 | 흩어진 기록이, / 한 화면으로 — 갤러리, 메모, 카톡에 흩어져 있던 시술 기록을 / 헤디 하나에 모았어요. |
| record | s4 | 600 | (eyebrow) 01 — 시술기록 저장 · 한 번의 시술이, / 한 장의 기록으로 — 사진 몇 장이면 기록이 끝납니다. / 스크롤을 내릴수록 기록이 시간순으로 쌓여요. |
| report | s5 | 220 | 12번의 기록이, / 나를 설명합니다 (지표: 모발 손상도 낮음 · 선호 톤 애쉬 계열 · 시술 주기 평균 7주) |
| recommend | s6 | 220 | 검색이 아니라, / 기록에서 시작하는 추천 |
| ar | s7 | 600 | 분할 문구 "거울 앞에 \| 앉기 전에" → 패널 문구 "머릿속 상상을 지우고 / 이제는 눈앞의 결과로" → 카피 "거울 앞에 앉기 전에, / 먼저 비춰보세요" |
| share | s8 | 320 | 미용실에서 / 설명 없이 — 기록이 나를 대신해 설명합니다 |
| closing | s9 | 100 | 다음 시술 전에, / 헤디에 기록부터 + Google Play / App Store 버튼 · © 2026 Heddy |

- 높이 = `100 + (base - 100) × scrollLength` (scrollLength 기본 1). 섹션 진행도 p = (scrollY − top) / (top + height − 뷰포트높이 − top), 0~1로 자름.
- 원본 s2는 삭제됨.
- 헤더: 로고 + "앱 다운로드" 버튼 → QR 팝오버("휴대폰으로 스캔하세요" + 스토어 버튼). 바깥 클릭·ESC로 닫힘.

## 2. 폰 목업 · 레이아웃

- 폰: 300×615, 프레임 `#1C1E20` radius 42, 화면은 inset 10px(280×595) radius 34, 배경 `#FBFBFB`. 그림자 `0 40px 70px -30px rgba(13,13,13,.45)`.
- 폰 두 대(A=메인, B=보조)는 **모든 섹션 위에 떠 있는 fixed 레이어 하나**에 있다.
- 배치: `translate(x−150, y−307.5) rotate(r) scale(S)`, (x,y)=폰 중심.
- 데스크톱(≥1024): S = min(1, H×0.78/615, W/1400), 중심 (0.7W, H/2+20). 카피는 좌측 max 40vw, 세로 가운데.
- 모바일(<1024): S = min(0.62, H×0.46/615, W/620), 중심 (0.5W, 0.7H). 카피는 상단 14vh부터.
- 이징은 전부 easeInOutCubic: `t<.5 ? 4t³ : 1−(−2t+2)³/2`.

## 3. 폰 A/B 자세 (R = 구간 진행도, E = 이징)

- **hero → archive 수렴**: c = E(R(p_archive, 0~0.72)). 회전축은 폰 하단 중심(pivot = 307.5×S).
  `V(off, deg) = [cx + off + pivot·sin(deg), cy + pivot − pivot·cos(deg)]`, tilt=12°, dx=(데스크톱 105 / 모바일 80)×S
  A = V(−dx(1−c), −tilt(1−c)), 회전 −tilt(1−c) / B = V(dx(1−c), tilt(1−c)), 회전 +tilt(1−c)
  B 불투명도 = 1 − R(p_archive, 0.72~0.86). archive 끝 이후 B = 0.
- **recommend 끝 ~ ar 시작**: A가 페이지와 함께 위로 빠짐 (yOffset = −(scrollY − recommend.end)).
- **ar**: A 재등장 yOffset = (1 − E(R(p_ar, 0.46~0.56))) × 90 × S, 불투명도 R(p_ar, 0.46~0.53).
- **share**(ar.end 이후): sh = E(R(p_share, 0.10~0.32)), back = E(R(scrollY, share.end~closing.top))
  A.x = lerp(lerp(cx, cx−0.13W, sh), cx, back) (모바일 0.29W) · B.x = lerp(lerp(W+220S, cx+0.13W, sh), W+220S, back) (모바일 0.73W)
  B 회전 lerp(lerp(10, 0, sh), 10, back), B는 sh>0 && back<1일 때만 보임. QR 비행 = R(p_share, 0.44~0.70).

## 4. 폰 화면 전환 (크로스페이드)

섹션 end 이후 뷰포트 높이의 35~65% 구간에서 다음 화면으로.
- ar 시작 전: 홈 → (archive 끝) 기록 → (record 끝) 리포트 → (report 끝) 추천
- ar 시작 후: AR → (ar 끝) QR 공유 → (share 끝 + 30~70%) 홈
- 폰 B: ar 전엔 AR 화면, 이후엔 스캔 → 웹뷰(R(p_share, 0.70~0.80))
- 폰 A가 AR 화면이면 상태바 글자 흰색.

화면 텍스트
- 홈: 다음 시술까지 D-12 · 레이어드 C컬펌 · 10월 첫째 주 권장 · 지난 컬러, 헤디가 기억해요(애쉬브라운 · 6레벨 · 2026.09) · 최근 기록(최근 3건) 전체 12
- 기록: 시술 기록 N건 (12행 리스트)
- 리포트: 헤어 리포트 · 12번의 기록 분석 · 모발 손상도 낮음 / 선호 톤 애쉬 계열 / 시술 주기 평균 7주 · 다음 시술 권장 10월 첫째 주
- 추천: 추천 스타일 · 내 기록 기반 · 애쉬브라운 레이어드 C컬 · 톤은 유지하고, 컬만 다시 · 태그(손상도 낮음 / 톤 유지 / 펌 주기 도래) · 근거 기록 3건(2026.07 헤어 클리닉, 2026.03 애쉬브라운 리터치, 2025.09 레이어드 C컬펌) · "세 개의 기록에서 나온 추천이에요"
- AR: 얼굴 인식 중 · 스타일 3종(내추럴 블랙 / 애쉬 브라운 / 다운펌 · 레이어드)
- QR 공유: 기록 공유 · 미용실에서 스캔하면 바로 열려요 → 기록을 전달했어요 · 링크는 24시간 동안 유효해요 · 공유되는 기록 12건 · 최근 시술 뿌리 염색
- B 스캔: QR을 비추면 기록이 열려요 / B 웹뷰: heddy.link/r/7Q2K · 앱 설치 없이 열림 · 헤디님의 시술 기록 · 12건 · 2025.03 – 2026.09 · 뿌리 염색 2026.09 · 사용 약제 6레벨 애쉬 · 산화제 3% · 모발 상태 손상도 낮음

## 5. 섹션별 모션

- **record (포커스 밴드)**: raw = R(p, 0.06~0.94)×11, k = min(10, ⌊raw⌋), fc = raw≥11 ? 11 : k + lerp(frac, E(frac), 0.5).
  행 j: y = 312 − 21 + (j − fc)×48, 거리 d = |j − fc|, f = clamp(1 − d), appear = clamp(fc − j + 1).
  흐린 행 opacity = f>0 ? 0 : 0.28×appear / 포커스 행 opacity (0.28 + 0.72f)×appear, transform translate(−52f, y) scale(1 + 0.04f), 배경 rgb(245,243,239)→흰색, 그림자 0.10f, 이름색 rgb(92,88,80)→rgb(13,13,13), 날짜색 rgb(163,158,148)→rgb(107,112,117).
  포커스 레이어는 폰 A와 같은 transform. 좌측 레일 scaleY(0.08 + 0.92p), "핀 진행 {8 + 92p}%".
  큰 날짜: 현재 기록 날짜, 색 rgb(214,208,196)→rgb(13,13,13) (fc/11), 캡션 "첫 기록" / "기록 N건 · Y년 M개월".
- **report**: 막대 i의 scaleX = E(R(scrollY, top − 0.3H + i·0.06H ~ top + 0.4L + i·0.06H)) × 값 (L = end − top). 섹션 막대와 폰 화면 막대 둘 다.
- **recommend**: 선 i의 strokeDashoffset = 1 − E(R(scrollY, top − 0.2H + i·0.12L ~ top + 0.2L + i·0.12L)), 미니 카드 opacity 0.35 + 0.65×R(v, 0.85~1).
- **ar**: a = E(R(p,.02~.10)), b = E(R(p,.10~.20)), c = E(R(p,.20~.28)).
  pill 교차축 26→58(a) → 데스크톱 0.5W(b), 주축 58→236(a) → 0.72H(b), 이후 W×H로(c), radius = min(w,h)/2 → 0(c). pill opacity R(p, 0~.02).
  "거울 앞에"/"앉기 전에"는 pill 좌우(모바일은 위아래)에 gap 20으로 밀려남.
  패널 문구 in R(p,.28~.33), out R(p,.40~.44), y (1−E(in))×24. 카피 in R(p,.46~.54), y (1−E)×20.
  스타일 전환: t2 = E(R(p,.62~.72)), t3 = E(R(p,.80~.90)), 가중치 [1−E(R(t2,.4~1)), t2(1−E(R(t3,.4~1))), t3] — 머리·색·라벨 opacity, 선택 칩 배경 rgba(255,255,255, .12+.88w).
  다크 패널이 화면을 덮은 동안(c>0.95) 헤더 배경 투명 + 로고 숨김.
- **share**: QR clip-path inset(0 0 (1−E(R(p,0~.16)))·100% 0), 비행 중엔 원래 QR 숨김.
  QR 비행: A 화면 (y − 57.5S) → B 화면 (y − 17.5S), 포물선 높이 200·S·4f(1−f), 회전 −10·sin(πf), scale lerp(1, .45, f)·S, 끝 fade R(f, .82~1).
  "기록을 전달했어요" R(p,.72~.80), 섹션 부제 R(p,.74~.88).
- **reduced motion**: 최종 상태로 두거나 opacity만.
