# 0002. 스크롤 모션 엔진: 순수 함수 + rAF (GSAP 미사용)

- 상태: 채택 · 2026-09-26 · 재검토 가능

## 결정

스크롤 위치 하나에서 모든 요소 상태를 계산하는 순수 함수(`(SceneFrame) => 값`) + requestAnimationFrame 1회 갱신. GSAP/ScrollTrigger는 넣지 않는다.

## 근거

- 디자인 원본(Claude Design v2)이 이미 이 방식이다. 수치를 그대로 옮기면 원본과 같은 결과가 나온다.
- 폰 두 대는 여러 섹션을 가로지르는 fixed 레이어라서, 섹션마다 pin을 거는 ScrollTrigger 모델과 맞지 않는다.
- 순수 함수라 vitest로 "진행도 x일 때 상태 y"를 단언할 수 있다 → 테스트가 곧 모션 명세.

## 다시 볼 조건

타임라인 편집 도구가 필요해지거나, 스크롤과 무관한 시간 기반 애니메이션이 많아지면 GSAP 도입을 검토.
